Päätin tätä kurssia varten vuokrata oman pilvipalvelimen. 

Valmistelua:
Asensin omalle vm:lle gitin.

Pystytän serverin upcloudin kautta

Kirjaudun root käyttäjällä serverille SSH-yhteydellä.

Ensitöikseni päivitän paketit.

Sitten teen sudokäyttäjän.

Luon käyttäjän komennolla
adduser johanna

Lisään käyttäjän sudo-ryhmään
usermod -aG sudo johanna

Tarkistan
groups johanna

Teen uuden SSH hakemiston ja kopioin SSH avaimen, sekä annan suoritusoikeuksia. Testaan toimiiko käyttäjän johanna SSH-yhteydellä kirjautuminen.

Poistan root kirjautumisen SSH:lla käytöstä ja poistan myös salasanalla kirjautumisen pois käytöstä muokkaamalla cfg-tiedostoa.

### Palomuurin asennus
Palomuurin asentaminen sudo apt-get install ufw 
Ennen palomuurin aktivointia sallitaan ssh-yhteys: sudo ufw allow ssh
Aktivoidaan palomuuri
Tarkistetaan status



### Apachen asennus

Asennan Apachen komennolla
sudo apt install apache2

Tarkistan statuksen
systemctl status apache2

Sallitaan http palomuurissa
sudo ufw allow http

Testataan toimiiko apache selaimella http://212.147.243.1

Toimii.
